# ad_markup_dataset

Dataset of ad creative markup (HTML / iframe / JS tags) — banner, safeframe,
JS redirect tags, GPT render tags, native HTML, rich-media expandable, nested
redirect. No VAST/VMAP/video.

## Files

- `ad_markup_dataset.json` — 896 records, fields: `id`, `source`, `format_type`,
  `vendor_style`, `width`, `height`, `adm`.
- `ad_markup_dataset_overlay.json` — same records plus `adm_with_overlay`: the
  `adm` wrapped in an iframe with a small badge showing the record's `id`.
- `generate.js` — regenerates the synthetic portion.
- `add_overlay.js` — regenerates the overlay field.

## Source

- `source: "prebid_fixture"` (112 records, `format_type: "unknown_banner"`) —
  extracted from [Prebid.js](https://github.com/prebid/Prebid.js) bidder
  adapter unit test fixtures (`test/spec/modules/*BidAdapter_spec.js`).
  Prebid.js is licensed Apache 2.0.
- `source: "synthetic_template"` (784 records) — generated by `generate.js`,
  templates modeled on real ad-server markup shapes (GAM, AppNexus, Criteo,
  TTD, Sizmek, Flashtalking, Celtra vendor styles) with placeholder domains
  (`*.example`) and macros. Not captured from live traffic.
